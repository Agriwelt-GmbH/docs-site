# Configurer un capteur de pression

Donnez son adresse à un capteur de pression d'air neuf ou remplacé.

Préparez d'abord comme dans [Configuration des appareils](device-configuration.md) : ce capteur seul sur le câble, niveau **« Agronomist »**. Le menu comporte les mêmes trois éléments que tout menu de configuration. Les valeurs d'adresse ne sont pas imprimées dans ce manuel : **prenez-les dans la fiche technique du système.**

::: steps
1. Ouvrez **« Service »** → **« Sensors Configuration »** (configuration des capteurs) → **« Pressure sensor »** (capteur de pression) — touchez chaque élément deux fois. Le menu montre **« Sensor address »** (adresse du capteur), **« New address »** (nouvelle adresse) et **« Set »** (valider).

2. Laissez **« Sensor address »** sur **« AUTO »**.

3. Touchez **« New address »**. Le panneau propose de lui-même la valeur du premier capteur de pression ; chaque capteur suivant prend la suivante. Comparez la valeur avec la fiche technique et corrigez-la au besoin par un glissement vers la droite ou vers la gauche.

4. Touchez **« Set »**, puis touchez-le de nouveau. Le panneau répond **« Done »** (terminé).

5. Débranchez le capteur et rebranchez-le. Sur l'écran d'accueil, vérifiez que son indicateur apparaît.
:::

Quand tous les capteurs sont faits, remettez le niveau sur **« Operator »**, ou éteignez puis rallumez le panneau. Ses paramètres : [Capteur de pression](pressure-sensor.md).
