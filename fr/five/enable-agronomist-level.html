Activer le niveau Agronomist

Comment faireHectare 5 firmware · 1.0.20Brouillon

Les étapes, au toucher, pour monter le niveau d'accès à Agronomist ou Service avant de modifier des réglages, puis revenir à Operator.

La plupart des travaux de mise en service — paramètres des capteurs, étalonnages, profil, configuration des appareils — exigent le niveau « Agronomist » (agronome). Le niveau « Service » (service) se monte de la même façon. Ce que chaque niveau ouvre : Niveaux d'accès.

Il vous faut le code du niveau voulu. Un code n'ouvre que son propre niveau : choisissez « Agronomist » et saisissez le code Agronomist.

  1. Sur l'écran d'accueil, touchez avec deux doigts. Le menu principal s'ouvre.

  2. Touchez « Settings » (réglages), puis touchez-le de nouveau. Le menu « Settings » s'ouvre.

  3. Repérez « User » (utilisateur) vers la fin du menu — glissez vers le haut s'il n'est pas visible — et touchez-le. Glissez vers la droite jusqu'à lire « Agronomist » (ou « Service »).

  4. Touchez de nouveau « User ». Le pavé numérique s'ouvre avec « Enter your PIN: » (saisissez votre code). Saisissez le code et touchez « OK ».

  5. Une courte fenêtre nomme le nouveau niveau, et le menu « Settings » revient avec les éléments de ce niveau — par exemple « Seeding machine parameters » (paramètres du semoir). Touchez en dehors du menu pour le quitter.

Un code erroné affiche « Invalid PIN » (code invalide) dans une fenêtre rouge, et le pavé numérique s'ouvre de nouveau. Pour renoncer, touchez en dehors du pavé numérique ; le niveau reste ce qu'il était.

IMPORTANT

Aux niveaux « Agronomist » et « Service », aucune fenêtre d'alarme ne s'affiche. Quand vous avez terminé, revenez au niveau « Operator » : répétez les étapes 1 à 3, glissez vers la gauche jusqu'à « Operator » et touchez de nouveau « User » — aucun code n'est demandé en descendant. Éteindre puis rallumer le panneau a le même effet.

Quand vous redescendez, les alarmes encore vraies s'affichent l'une après l'autre. Voir Niveaux d'accès.
