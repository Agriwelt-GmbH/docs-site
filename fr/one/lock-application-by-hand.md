# Verrouiller l'application du produit à la main

Arrêter toute application de produit par un appui long, puis la relancer — ce que fait le verrouillage et comment voir qu'il est actif.

Le verrouillage manuel arrête **toute application de produit** : les moteurs de doseur et la pompe ne tournent pas, quoi que fasse la machine. Utilisez-le pour traverser un champ déjà semé, pour rouler sur route avec la machine abaissée, ou lorsque vous travaillez [sans capteur de vitesse](work-without-speed-sensor.md).

::: steps
1. Sur l'écran d'accueil, **maintenez « HOME »** jusqu'à ce que le panneau émette un bip.

2. Regardez le bord droit de l'écran. Une **main jaune** y clignote : l'application est verrouillée.

   ![](figures/icons/hand.png){height=48px}

3. Pour déverrouiller, maintenez de nouveau **« HOME »**. Un bip court ; la main disparaît.
:::

Sur le deuxième écran d'accueil, la même action fonctionne avec **« HOME »**, ou en touchant et maintenant la main.

> **IMPORTANT**
>
> **Le verrouillage n'est annoncé que par l'écran.** Cherchez la main jaune avant de commencer un passage. Une machine verrouillée parcourt un champ entier et ne sème rien.

## Ce que le verrouillage change ailleurs {#what-the-lock-changes-elsewhere}

- Les vignettes de moteur de l'[écran Motors](motors-screen.md) montrent un **STOP** jaune — en état de marche, sans application.
- L'indicateur de débit de la pompe montre une pompe jaune avec **STOP** ([Pompe d'engrais liquide](indicators.md#liquid-fertilizer-pump)).
- La commande d'application du produit ne démarre pas quand vous avancez — le verrouillage doit être désactivé pour que la commande démarre ([Démarrage rapide](quick-start.md#moving-off)).
- Le travail effectué verrouillé est compté dans les statistiques sous **Work without alarms control** ([Statistics](statistics-screen.md)).

La main jaune s'affiche sur les machines à moteurs électriques de doseur ou à pompe d'engrais liquide.
