# Activer le niveau Agronomist

Les étapes, avec l'écran de chacune, pour passer au niveau d'accès Agronomist ou Service avant de modifier des réglages, puis revenir au niveau Operator.

La plupart des travaux de réglage — paramètres des capteurs, étalonnages, configuration des appareils — exigent le niveau **« Agronomist »** (agronome). Le niveau **« Service »** (service après-vente) s'active de la même manière. Ce que permet chaque niveau : [Niveaux d'accès](access-levels.md).

Il vous faut le code PIN de ce boîtier. Il est différent pour chaque boîtier ; reportez-vous au passeport de l'appareil ou adressez-vous au support technique.

::: steps
1. Sur l'écran d'accueil, appuyez sur **« MENU »**. Le menu principal s'ouvre.

   ![Le menu principal.](figures/menu-main)

2. Sélectionnez **« Settings »** (réglages) avec **« UP »** / **« DOWN »** et appuyez sur **« MENU »**. Le menu **« Settings »** s'ouvre.

   ![Le menu Settings au niveau Operator.](figures/menu-settings)

3. Appuyez sur **« DOWN »** jusqu'à sélectionner **« User »** (utilisateur) — la rubrique se trouve vers la fin du menu. Appuyez sur **« PLUS »** jusqu'à lire **« Agronomist »** (ou **« Service »**).

   ![« User » réglé sur Agronomist.](figures/menu-user-agronomist)

4. Appuyez sur **« MENU »**. Le clavier de code PIN s'ouvre. Son titre indique le niveau choisi — **« Agronomist »** (agronome) — suivi du code de ce boîtier ; gardez ce code sous la main lorsque vous demandez le code PIN au support technique. Tapez le code PIN et touchez **« OK »**.

   ![Le clavier de code PIN. Le code affiché à côté de l'invite est masqué dans ce manuel.](figures/pin-entry)

5. Le menu **« Settings »** réapparaît, avec désormais les rubriques du nouveau niveau — par exemple **« Seeding machine parameters »** (paramètres du semoir). Appuyez sur **« BACK »** pour quitter.
:::

> **IMPORTANT**
>
> **Aux niveaux « Agronomist » et « Service », aucune fenêtre d'alarme n'est affichée.** Quand vous avez terminé, revenez au niveau **« Operator »** : répétez les étapes 1 à 3, choisissez **« Operator »** avec **« MINUS »** et appuyez sur **« MENU »** — aucun code PIN n'est demandé en descendant. Éteindre puis rallumer le boîtier produit le même effet.

Quand vous redescendez, les alarmes encore vraies s'affichent l'une après l'autre. Voir [Niveaux d'accès](access-levels.md#what-happens-to-the-alarms-while-the-level-is-high).
