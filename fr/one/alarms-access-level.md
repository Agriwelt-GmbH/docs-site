# User is Agronomist : les alarmes ne seront pas affichées

Pourquoi le boîtier avertit que les alarmes sont masquées, et comment les retrouver.

Fonctionnement de la fenêtre : [Fonctionnement des alarmes](how-alarms-work.md).

## « User is Agronomist! » / « Alarms will not be shown! » — utilisateur Agronomist ! les alarmes ne seront pas affichées {#user-is-agronomist-alarms-will-not-be-shown}

**Ce que cela signifie.** Les conditions de surveillance de l'application du produit sont réunies — la machine travaille — alors que le niveau d'accès **« Agronomist »** (agronome) est actif. À ce niveau, le boîtier n'affiche pas les fenêtres d'alarme. Le message n'apparaît qu'**une seule fois** pendant tout le temps où vous travaillez à ce niveau.

**Que faire :** remettez le niveau d'accès sur **« Operator »** (opérateur) :

::: steps
1. Appuyez sur **« MENU »** sur l'écran d'accueil et sélectionnez **« Settings »** (réglages).

2. Sélectionnez **« User »** (utilisateur) et choisissez **« Operator »** avec **« PLUS »** / **« MINUS »**.

3. Appuyez sur **« MENU »**. Descendre d'un niveau n'exige pas de code PIN.
:::

Éteindre puis rallumer le boîtier produit le même effet : après chaque mise sous tension, le boîtier démarre au niveau **« Operator »**.

> **REMARQUE**
>
> **Attendez-vous à une courte série d'alarmes au retour.** Les alarmes déclenchées pendant que le niveau était élevé ont attendu. Le boîtier écarte celles qui ont disparu et affiche celles qui sont toujours vraies. C'est l'arriéré, et non un nouveau défaut. Voir [Niveaux d'accès](access-levels.md).
