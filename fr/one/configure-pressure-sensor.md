# Configurer un capteur de pression

Attribuer son adresse à un capteur de pression d'air neuf ou remplacé.

Préparez d'abord comme dans [Configuration des appareils](device-configuration.md) : ce capteur seul sur le câble, niveau **« Agronomist »** (agronome). Le menu comporte les trois mêmes rubriques que tout menu de configuration. Les valeurs d'adresse ne sont pas imprimées dans ce manuel : **prenez-les dans la fiche technique du système.**

::: steps
1. Choisissez **« Service »** → **« Sensors Configuration »** (configuration des capteurs) → **« Pressure sensor »** (capteur de pression) et appuyez sur **« MENU »**. Le menu affiche **« Sensor address »** (adresse du capteur), **« New address »** (nouvelle adresse) et **« Set »** (valider).

2. Laissez **« Sensor address »** sur **« AUTO »**.

3. Sélectionnez **« New address »**. Le boîtier propose de lui-même la valeur correcte pour le premier capteur de pression ; chaque capteur suivant prend la valeur suivante. Comparez la valeur avec la fiche technique et corrigez-la au besoin avec **« PLUS »** / **« MINUS »**.

4. Sélectionnez **« Set »** et appuyez sur **« MENU »**. Le boîtier répond **« Done »** (terminé).

5. Débranchez le capteur et rebranchez-le. Sur l'écran d'accueil, vérifiez que son indicateur apparaît.
:::

Quand tous les capteurs sont faits, remettez le niveau sur **« Operator »** (opérateur), ou éteignez puis rallumez le boîtier. Ses paramètres : [Capteur de pression](pressure-sensor.md).
