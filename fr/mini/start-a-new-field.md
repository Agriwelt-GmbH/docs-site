# Commencer le travail sur une nouvelle parcelle

Choisir la parcelle dans laquelle le panneau écrit ses statistiques, et l'effacer si elle n'est pas vide — avant le premier passage sur une nouvelle parcelle.

Le panneau conserve les statistiques de plusieurs parcelles. Il écrit dans l'une d'elles, la **parcelle active**, marquée **(A)** sur l'[écran Statistics](statistics-screen.md). Avant le premier passage sur une nouvelle parcelle, faites d'une parcelle vide la parcelle active.

::: steps
1. Sur l'écran d'accueil, appuyez deux fois sur **« HOME »**. L'écran Statistics s'ouvre sur la parcelle active.

2. Appuyez sur **« PLUS »** ou **« MINUS »** jusqu'à ce que la parcelle voulue soit affichée. Les parcelles sans **(A)** ne sont pas actives.

3. Appuyez sur **« MENU »**. Le menu de l'écran s'ouvre.

   ![Le menu de l'écran Statistics.](figures/stat-menu)

4. Sélectionnez **« Select field »** (sélectionner la parcelle) et appuyez sur **« MENU »**. L'élément n'est affiché que pour une parcelle qui n'est pas active.

5. Le panneau demande **« Are you sure? »** (êtes-vous sûr ?). Appuyez sur **« PLUS »** pour **« Yes »** (oui). La parcelle est maintenant active, marquée **(A)**, et les relevés du tableau de semis repartent de zéro.
:::

Si la parcelle contient déjà des données d'autres produits que ceux que la machine applique maintenant, le panneau demande d'abord d'effacer cette parcelle ; au niveau Operator, il veut aussi le code d'un niveau d'accès supérieur.

## Effacer une parcelle qui contient d'anciennes données {#erase-a-field-that-holds-old-data}

::: steps
1. Affichez la parcelle sur l'écran Statistics et appuyez sur **« MENU »**.

2. Sélectionnez **« Zero statistics »** (remettre les statistiques à zéro) et appuyez sur **« MENU »**.

3. Au niveau Operator, saisissez le code du niveau Agronomist sur le [pavé numérique](number-pad.md). Au-dessus du niveau Operator, le panneau demande **« Are you sure? »** — appuyez sur **« PLUS »** pour **« Yes »**.
:::

Les statistiques de cette parcelle sont effacées définitivement. Les totaux cumulés sous **« Mileage »** (kilométrage) ne sont pas touchés.

> **IMPORTANT**
>
> **Les statistiques peuvent aussi être effacées par d'autres modifications.** Mettre un moteur sous ou hors surveillance, ou changer le type de produit d'un moteur, peut exiger que les statistiques de la parcelle active soient d'abord effacées. Passez à une parcelle vide avant de telles modifications si vous voulez conserver les données.
