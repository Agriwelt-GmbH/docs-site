# Kornsensor konfigurieren

Geben Sie einem neuen oder ausgetauschten Kornsensor die Nummer seiner Reihe.

Bei einem Kornsensor ist die neue Adresse schlicht **die Nummer der Reihe** – dieselbe Nummer, die der Fahrer auf dem Startbildschirm unter der Spalte sieht. Bereiten Sie zuerst vor wie in [Gerätekonfiguration](device-configuration.md): nur dieser Sensor am Kabel, Ebene **„Agronom“**.

Die Adresse eines Kornsensors lässt sich nur ändern, solange der Sensor **normal arbeitet**. Ein Rohrsensor ist bereit, sobald er angeschlossen ist. Ein **offener** Sensor muss auf seinem Halter sitzen oder so gehalten werden, dass **kein Tageslicht in den optischen Kanal fällt** – den Spalt zwischen den beiden Gläsern. Bei direktem Licht meldet der Sensor einen dauernden Kornfluss und nimmt die neue Adresse nicht an.

::: steps
1. Wählen Sie **„Service“** → **„Sensorkonfiguration“** → **„Kornsensor“** und drücken Sie **„MENU“**. Das Menü hat drei Punkte.

   ![Das Konfigurationsmenü „Kornsensor“.](figures/konf-seed)

2. Lassen Sie **„Sensoradresse“** auf **„AUTO“**.

3. Wählen Sie **„Neue Adresse“** und stellen Sie die Reihennummer mit **„PLUS“** / **„MINUS“** ein.

4. Wählen Sie **„Einstellen“** und drücken Sie **„MENU“**. Das Panel antwortet **„Fertig“**.

   ![Das Panel bestätigt mit „Fertig“.](figures/info-done)

5. Trennen Sie den Sensor und schließen Sie ihn wieder an. Prüfen Sie auf dem Startbildschirm, dass er unter seiner Reihe erscheint.
:::

Sind alle Sensoren fertig, stellen Sie die Ebene wieder auf **„Fahrer“** oder schalten Sie das Panel aus und wieder ein.
