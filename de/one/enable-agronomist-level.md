# Agronomen-Ebene aktivieren

Die Schritte, jeweils mit dem zugehörigen Bildschirm, um die Zugriffsebene vor dem Ändern von Einstellungen auf „Agronom“ oder „Service“ anzuheben und danach auf „Fahrer“ zurückzukehren.

Die meisten Einrichtungsarbeiten – Sensorparameter, Kalibrierungen, Gerätekonfiguration – erfordern die Ebene **„Agronom“**. Die Ebene **„Service“** wird auf dieselbe Weise angehoben. Was jede Ebene erlaubt: [Zugriffsebenen](access-levels.md).

Sie brauchen die PIN dieses Panels. Sie ist für jedes Panel eine andere; Sie steht im Gerätepass, oder Sie erfragen sie beim Service-Support.

::: steps
1. Drücken Sie auf dem Startbildschirm **„MENU“**. Das Hauptmenü öffnet sich.

   ![Das Hauptmenü.](figures/menu-main)

2. Wählen Sie mit **„UP“** / **„DOWN“** den Punkt **„Einstellungen“** und drücken Sie **„MENU“**. Das Menü **„Einstellungen“** öffnet sich.

   ![Das Menü Einstellungen auf der Ebene Fahrer.](figures/menu-settings)

3. Drücken Sie **„DOWN“**, bis **„Benutzer“** markiert ist – er steht nahe am Ende des Menüs. Drücken Sie **„PLUS“**, bis dort **„Agronom“** (oder **„Service“**) steht.

   ![„Benutzer“ auf Agronom eingestellt.](figures/menu-user-agronomist)

4. Drücken Sie **„MENU“**. Das PIN-Feld öffnet sich. Seine Überschrift nennt die gewählte Ebene – **„Agronom“** – und dahinter den Code dieses Panels; halten Sie diesen Code bereit, wenn Sie die PIN beim Service-Support erfragen. Geben Sie die PIN ein und berühren Sie **„OK“**.

   ![Das PIN-Feld. Der Code neben der Aufforderung ist in dieser Anleitung verdeckt.](figures/pin-entry)

5. Das Menü **„Einstellungen“** erscheint wieder, nun mit den Punkten der neuen Ebene – zum Beispiel **„Sämaschinen-Parameter“**. Drücken Sie **„BACK“**, um es zu verlassen.
:::

> **WICHTIG**
>
> **Auf den Ebenen „Agronom“ und „Service“ werden keine Alarmfenster angezeigt.** Kehren Sie nach der Arbeit auf **„Fahrer“** zurück: Wiederholen Sie die Schritte 1–3, wählen Sie mit **„MINUS“** den Wert **„Fahrer“** und drücken Sie **„MENU“** – nach unten wird keine PIN abgefragt. Auch Aus- und Einschalten des Panels bewirkt dasselbe.

Wenn Sie wieder herunterschalten, werden die Alarme, die weiterhin zutreffen, nacheinander angezeigt. Siehe [Zugriffsebenen](access-levels.md#what-happens-to-the-alarms-while-the-level-is-high).
