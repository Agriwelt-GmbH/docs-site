# Drucksensor konfigurieren

Geben Sie einem neuen oder ausgetauschten Luftdrucksensor seine Adresse.

Bereiten Sie zuerst vor wie in [Gerätekonfiguration](device-configuration.md): nur dieser Sensor am Kabel, Ebene **„Agronom“**. Das Menü hat dieselben drei Punkte wie jedes Konfigurationsmenü. Die Adresswerte sind in dieser Anleitung nicht abgedruckt: **Entnehmen Sie sie dem Datenblatt des Systems.**

::: steps
1. Wählen Sie **„Service“** → **„Sensorkonfiguration“** → **„Drucksensor“** und drücken Sie **„MENU“**. Das Menü zeigt **„Sensoradresse“**, **„Neue Adresse“** und **„Einstellen“**.

2. Lassen Sie **„Sensoradresse“** auf **„AUTO“**.

3. Wählen Sie **„Neue Adresse“**. Das Panel schlägt für den ersten Drucksensor selbst den richtigen Wert vor; jeder weitere Sensor erhält den nächsten. Prüfen Sie den Wert anhand des Datenblatts und korrigieren Sie ihn bei Bedarf mit **„PLUS“** / **„MINUS“**.

4. Wählen Sie **„Einstellen“** und drücken Sie **„MENU“**. Das Panel antwortet **„Fertig“**.

5. Trennen Sie den Sensor und schließen Sie ihn wieder an. Prüfen Sie auf dem Startbildschirm, dass seine Anzeige erscheint.
:::

Sind alle Sensoren fertig, stellen Sie die Ebene wieder auf **„Fahrer“** oder schalten Sie das Panel aus und wieder ein. Seine Parameter: [Drucksensor](pressure-sensor.md).
