# Drucksensor konfigurieren

Geben Sie einem neuen oder ersetzten Luftdrucksensor seine Adresse.

Bereiten Sie zuerst vor wie in [Gerätekonfiguration](device-configuration.md): nur dieser Sensor am Kabel, Ebene **„Agronomist“** (Agronom). Das Menü hat dieselben drei Punkte wie jedes Konfigurationsmenü. Die Adresswerte sind in dieser Anleitung nicht abgedruckt: **Entnehmen Sie sie dem Datenblatt des Systems.**

::: steps
1. Öffnen Sie **„Service“** (Service) → **„Sensors Configuration“** (Sensorkonfiguration) → **„Pressure sensor“** (Drucksensor) — tippen Sie jeden Punkt zweimal an. Das Menü zeigt **„Sensor address“** (Sensoradresse), **„New address“** (Neue Adresse) und **„Set“** (Setzen).

2. Lassen Sie **„Sensor address“** auf **„AUTO“** (automatisch).

3. Tippen Sie auf **„New address“**. Das Panel schlägt den Wert für den ersten Drucksensor von selbst vor; jeder weitere Sensor nimmt den nächsten. Prüfen Sie den Wert anhand des Datenblatts und korrigieren Sie ihn bei Bedarf mit einem Wisch nach rechts oder links.

4. Tippen Sie auf **„Set“** und noch einmal darauf. Das Panel antwortet **„Done“** (Fertig).

5. Trennen Sie den Sensor und schließen Sie ihn wieder an. Prüfen Sie auf dem Startbildschirm, dass seine Anzeige erscheint.
:::

Sind alle Sensoren fertig, setzen Sie die Ebene zurück auf **„Operator“** (Fahrer) oder schalten Sie das Panel aus und wieder ein. Seine Parameter: [Drucksensor](pressure-sensor.md).
