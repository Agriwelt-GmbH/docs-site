Agronomen-Ebene aktivieren

AnleitungHectare Mini firmware · 2.2.8

Die Schritte, jeweils mit dem zugehörigen Bildschirm, um die Zugriffsebene des Hectare Mini vor dem Ändern von Einstellungen auf „Agronom“ oder „Service“ anzuheben und danach auf „Fahrer“ zurückzukehren.

Sensorparameter, Arbeitsbreite, Kalibrierungen und Gerätekonfiguration erfordern die Ebene „Agronom“. Die Ebene „Service“ wird auf dieselbe Weise angehoben. Was jede Ebene freigibt: Zugriffsebenen.

Sie brauchen die PIN dieses Panels für die jeweilige Ebene. Sie ist bei jedem Panel anders; Sie erhalten sie vom Händler.

  1. Drücken Sie auf dem Startbildschirm „MENU“. Das Hauptmenü öffnet sich.

  2. Wählen Sie mit „UP“ / „DOWN“ den Punkt „Einstell.“ und drücken Sie „MENU“. Das Menü „Einstell.“ öffnet sich.

  3. Drücken Sie „DOWN“, bis „Benutzer“ markiert ist – er ist der letzte Punkt. Drücken Sie „PLUS“, bis dort „Agronom“ (oder „Service“) steht.

  4. Drücken Sie „MENU“. Das PIN-Feld öffnet sich mit „PIN eingeben:“; die Zeile unter der Aufforderung kennzeichnet dieses Panel. Geben Sie die PIN über das Zahlenfeld ein und berühren Sie „OK“ oder drücken Sie „MENU“.

  5. Das Panel zeigt kurz den Namen der neuen Ebene und kehrt zum Menü „Einstell.“ zurück, nun mit den Punkten dieser Ebene – zum Beispiel „Sämaschinen-Parameter“.

  6. Drücken Sie „BACK“, um das Menü zu verlassen.

Ist die PIN falsch – oder gehört sie zu einer anderen Ebene als der in Schritt 3 gewählten –, zeigt das Panel kurz „Ungültige PIN“ und öffnet das PIN-Feld erneut. Geben Sie die PIN noch einmal ein oder drücken Sie „BACK“, um abzubrechen; die Ebene bleibt, wie sie war.

WICHTIG

Auf den Ebenen „Agronom“ und „Service“ werden keine Alarmfenster angezeigt. Kehren Sie nach der Arbeit auf „Fahrer“ zurück: Wiederholen Sie die Schritte 1–3, wählen Sie mit „MINUS“ den Wert „Fahrer“ und drücken Sie „MENU“ – nach unten wird keine PIN abgefragt. Auch Aus- und Einschalten des Panels bewirkt dasselbe.

Wenn Sie wieder herunterschalten, werden die Alarme, die weiterhin zutreffen, nacheinander angezeigt – siehe Zugriffsebenen.
