# Die Arbeit auf einem neuen Feld beginnen

Wählen Sie das Feld, in das das Panel seine Statistik schreibt, und löschen Sie es, wenn es nicht leer ist — vor der ersten Fahrt auf einem neuen Feld.

Das Panel führt die Statistik mehrerer Felder. Es schreibt in eines davon, das **aktive Feld**, auf dem [Bildschirm Statistik](statistics-screen.md) mit **(A)** gekennzeichnet. Machen Sie vor der ersten Fahrt auf einem neuen Feld ein leeres Feld zum aktiven.

::: steps
1. Drücken Sie auf dem Startbildschirm zweimal **„HOME“**. Der Bildschirm Statistik öffnet sich mit dem aktiven Feld.

2. Drücken Sie **„PLUS“** oder **„MINUS“**, bis das gewünschte Feld angezeigt wird. Felder ohne **(A)** sind nicht aktiv.

3. Drücken Sie **„MENU“**. Das Menü des Bildschirms öffnet sich.

   ![Das Menü des Bildschirms Statistik.](figures/stat-menu)

4. Wählen Sie **„Feld wählen“** und drücken Sie **„MENU“**. Der Punkt wird nur bei einem Feld angezeigt, das nicht aktiv ist.

5. Das Panel fragt **„Sind Sie sicher?“**. Drücken Sie **„PLUS“** für **„Ja“**. Das Feld ist jetzt aktiv, mit **(A)** gekennzeichnet, und die Werte der Saattabelle beginnen bei null.
:::

Enthält das Feld bereits Daten zu anderen Produkten, als die Maschine jetzt ausbringt, verlangt das Panel zuerst, dieses Feld zu löschen; auf der Stufe „Fahrer“ will es außerdem den Code einer höheren Zugriffsstufe.

## Ein Feld mit alten Daten löschen {#erase-a-field-that-holds-old-data}

::: steps
1. Zeigen Sie das Feld auf dem Bildschirm Statistik an und drücken Sie **„MENU“**.

2. Wählen Sie **„Statistik zurücksetzen“** und drücken Sie **„MENU“**.

3. Geben Sie auf der Stufe „Fahrer“ den Code der Stufe „Agronom“ am [Ziffernblock](number-pad.md) ein. Oberhalb von „Fahrer“ fragt das Panel **„Sind Sie sicher?“** — drücken Sie **„PLUS“** für **„Ja“**.
:::

Die Statistik dieses Feldes wird endgültig gelöscht. Die Summen über die Lebensdauer unter **„Wegstrecke“** bleiben unberührt.

> **WICHTIG**
>
> **Die Statistik kann auch durch andere Änderungen gelöscht werden.** Einen Motor in die Überwachung zu nehmen oder aus ihr zu nehmen oder den Produkttyp eines Motors zu ändern, kann verlangen, dass zuerst die Statistik des aktiven Feldes gelöscht wird. Wechseln Sie vor solchen Änderungen zu einem leeren Feld, wenn Sie die Daten behalten wollen.
