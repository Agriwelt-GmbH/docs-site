How to…

  • Change the target rateRaise or lower the rate the panel holds and guards, from the home screen, while seeding — by touch.
  • Lock product application by handStop all product application with one touch and hold, and start it again — what the lock does and how to see that it is on.
  • Set the alarm level automaticallyLet the panel set the alarm level of the diagrams from the rate the machine really sows, with one double tap — grain drills in the "Flow" or "Hybrid" mode.
  • Take a sensor into or out of controlStop the panel from watching one sensor — a section that is shut off, a broken sensor — and take it back later.
  • Zero the readings of the Table screenSet the seed and fertilizer counters of the Table screen to zero — for a new field or a new seed lot — without touching the field statistics.
  • Fill the disks with seedsTurn the seed disks of a planter with dispenser motors until every disk holds seed, so that sowing starts from the first metre — how to run it and read the result.
  • Set up the tramline rhythmWhat a tramline rhythm is, worked out for your drill and sprayer, how to set it up on the panel by touch, and how the panel counts the bouts.
  • Set the screen brightnessMake the screen brighter or dimmer — one item in the Settings menu, set by hand.
  • Work without the speed sensorWhen the speed sensor fails in the field — take the speed from GPS, or finish the work on a simulated speed and control the application by hand.

  • Tramline actuatorThe two parameters of the tramline actuator, where the rest of its settings live, and what its status screen shows.
  • Device configuration — before you startWhat device configuration is, the preparation it needs, and the three-item pattern every configuration menu follows.

  • Configure a pressure sensorGive a new or replaced air pressure sensor its address.

  • Configure a tramline actuator controllerTell an actuator controller which tramline actuator it drives and which marker sensors are wired to it.
  • Configure the motor controllersGive a metering motor controller its address, choose the kind of controller, and set its parameters.
  • Motor controller diagnosticsHow to read what a metering motor controller reports about itself on the Electric motors screen — speed, error code, voltages, temperature, current, status bits and fault counters — and how to move through it by touch.

  • Fan or dispenser shaft: speed alarmsWhat to do when the fan or the dispenser shaft turns too slowly, too fast, or not at all.
