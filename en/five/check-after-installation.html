Check the system after installation

How toHectare 5 firmware · 1.0.20Draft

A step-by-step check to run once after mounting — every device answers, every seed sensor sits in its own row, the counting, work position, speed and the other sensors work — and what to record.

Run this check once, after the system is mounted and before the first field. Each step says what to do, what the screen must show, and where to go if it does not. Your machine may not have every device — skip the steps for what it does not have.

Start at the “Operator” level: it is the level at which alarm windows are shown (Access levels). The panel starts at that level after every power-on.

  1. Check that every device answers. Switch the panel on and wait for the home screen (Switching on).

    • The profile must match the machine: the number of seed sensors equals the number of rows, and the other devices are the ones the machine has (The profile). The machine settings are in Seeding machine parameters; the sensor parameters to check are listed in Quick start.
    • No alarm window “Connection lost”, no red indicator with a ×, no white indicator with !, no red indicator with ? (Indicators).
    • Open the status screen of a device: touch and hold it, then “Information”. Swipe left or right through every device of the list. “Link:” must read “Normal” on each (The sensor status screen).
    • A seed or fertilizer sensor must show Status: Working.

    If it does not: Connection lost or wrong device · Sensor clogged or broken · a device that is out of control: Take a sensor into or out of control.

  2. Check that every seed sensor sits in its own row. The machine stands still. Open the Table screen with a long swipe to the left on the home screen. Tap it with two fingers and touch “Yes” to the question “Zero readings?” (Zero the readings). Then drop a few seeds by hand through the seed tube of row 1, one after another. Instead of seeds you may pass any small object, for example a long cable tie, through the seed tube several times — each pass is counted. Do the same for row 2, row 3 and so on, up to the last row.

    • Only the line of the row you dropped into reacts. In the “Precise” mode, switch to the table of the seed counters with a long two-finger swipe — the count of that row grows (The Table screen). Read the count on that table, which shows the number of seeds, not on the view with seeds per metre: that view shows values only while the machine moves. In the other modes, watch sds/s of that row.
    • A line of another row reacts: that sensor is connected in the wrong order. Correct the order of the connections and repeat the drop.
    • No line reacts: see step 1 for that sensor.

    If it does not: Connection lost or wrong device · Sensor clogged or broken.

  3. Check the counting. Zero the readings again, as in step 2. Drop a known number of seeds, for example 20, one by one through the seed tube of one row. Read the count of that row on the table of the seed counters (“Precise” mode), the table that shows the number of seeds. On a precision planter it matches the number you dropped to within one seed, provided the “Fraction” of the seed sensors is set for the size of the seed. Write both numbers down. Repeat for one more row. If the figure is clearly higher — up to twice the number — the fraction is set too small for this seed: a large seed, for example maize, is then counted as two. Set the fraction by the table in Seed sensors and dry fertilizer sensors.

    If it does not: write down both figures and see Before you contact support.

  4. Check the work position sensor. Lower the machine into the working position, then raise it into the transport position.

    • The implement position indicator is green when lowered, yellow and blinking when raised (Indicators).
    • On the status screen of the sensor, “Position: Working” and “Position: Transporting” follow the machine.
    • If both are the wrong way round, check the setting “Transporting position signal” (Hopper, work position and engine sensors).

  5. Check the speed. Calibrate the speed sensor first if you have not (Calibrate the speed sensor). Then drive.

    • The speed field shows a white figure. It matches the speed of the tractor.
    • It does not show XX.X, !!.! or ????.
    • On the status screen of the speed sensor, the frequency F= changes while you drive.

    If it does not: Speed sensor alarms · Travel speed sensor · Work without the speed sensor.

  6. Check the other sensors the machine has. One short check each:

    • Hopper. The hopper icon is full and green with product in the hopper. Hopper empty.
    • Fan. Start the fan. The fan icon is green and shows the speed in rpm. Fan or dispenser shaft: speed alarms.
    • Air pressure. The pressure icon is green and shows the pressure in kPa while the fan runs. Air pressure.
    • Dispenser shaft. While the shaft turns, the metering unit icon turns. Fan or dispenser shaft: speed alarms.
    • Markers. Lower and raise the markers. The marker icon shows the arm or arms down or up (Indicators).
    • Dispenser motors and tramline actuators. Open the Motors screen. Every tile shows its value; none has a red × (The Motors screen).
    • Engine sensors. The engine indicators the machine has are green; the ignition key is green with the ignition on (Indicators).

  7. Record the result.

    • Two-finger tap on the home screen, then “About”. Write down the firmware version and the serial number. Close the window with “Close”.
    • Write down the date and the machine.
    • Photograph the status screen of the sensors — at least the screens that show a device with its link and its state.

Keep the record and the photos. If you need help later, they are the first thing support asks for (Before you contact support).

If a step fails

Step Go to
1. A device does not answer Connection lost or wrong device
1. A seed sensor reports a fault Sensor clogged or broken
1. A device is out of control Take a sensor into or out of control
1. The profile does not match the machine The profile
2, 3. A row does not react, reacts in another row, or the count is wrong Connection lost or wrong device, then Before you contact support
4. The position does not follow the machine Hopper, work position and engine sensors
5. No speed or a wrong speed Speed sensor alarms, Calibrate the speed sensor, Work without the speed sensor
6. Hopper Hopper empty
6. Fan, dispenser shaft Fan or dispenser shaft: speed alarms
6. Air pressure Air pressure
Any other fault How alarms work
