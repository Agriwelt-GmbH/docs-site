# Enable the Agronomist level

The steps, by touch, to raise the access level to "Agronomist" or "Service" before changing settings, and to return to "Operator" afterwards.

Most set-up work — sensor parameters, calibrations, the profile, device configuration — needs the **“Agronomist”** level. The **“Service”** level is raised the same way. What each level opens: [Access levels](access-levels.md).

You need the PIN of the level you want. A PIN opens only its own level: choose **“Agronomist”** and type the Agronomist PIN.

::: steps
1. On the home screen tap with **two fingers**. The main menu opens.

   ![The main menu.](figures/five-main-menu)

2. Tap **“Settings”**, and tap it again. The **“Settings”** menu opens.

   ![The Settings menu at the Operator level.](figures/five-menu-settings)

3. Find **“User”** near the end of the menu — swipe up if it is not in view — and tap it. Swipe right until it reads **“Agronomist”** (or **“Service”**).

   ![“User” set to Agronomist.](figures/five-menu-user-agronomist)

4. Tap **“User”** again. The number pad opens with **“Enter your PIN:”**. Type the PIN and tap **“OK”**.

   ![The number pad asking for the PIN.](figures/five-pin-pad)

5. A short window names the new level, and the **“Settings”** menu returns with the items of that level — for example **“Seeding machine parameters”**. Tap outside the menu to leave.
:::

A wrong PIN shows **“Invalid PIN”** in a red window, and the number pad opens again. To give up, tap outside the number pad; the level stays as it was.

> **IMPORTANT**
>
> **At “Agronomist” and “Service” no alarm windows are shown.** When you have finished, return to **“Operator”**: repeat steps 1–3, swipe left to **“Operator”** and tap **“User”** again — no PIN is asked going down. Switching the panel off and on does the same.

When you come back down, the alarms that are still true are shown one after another. See [Access levels](access-levels.md#what-happens-to-the-alarms-while-the-level-is-high).
