# Configure a pressure sensor

Give a new or replaced air pressure sensor its address.

Prepare first as in [Device configuration](device-configuration.md): only this sensor on the cable, **“Agronomist”** level. The menu has the same three items as every configuration menu. The address values are not printed in this manual: **take them from the data sheet of the system.**

::: steps
1. Choose **“Service”** → **“Sensors Configuration”** → **“Pressure sensor”** and press **“MENU”**. The menu shows **“Sensor address”**, **“New address”** and **“Set”**.

2. Leave **“Sensor address”** at **“AUTO”**.

3. Select **“New address”**. The panel proposes the correct value for the first pressure sensor by itself; each further sensor takes the next one. Check the value against the data sheet and correct it with **“PLUS”** / **“MINUS”** if needed.

4. Select **“Set”** and press **“MENU”**. The panel answers **“Done”**.

5. Disconnect the sensor and connect it again. On the home screen, check that its indicator appears.
:::

When all sensors are done, set the level back to **“Operator”**, or switch the panel off and on. Its parameters: [Pressure sensor](pressure-sensor.md).
