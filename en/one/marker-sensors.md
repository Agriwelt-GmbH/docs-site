# Marker sensors

The parameters of the marker sensors — which marker a sensor watches and which input state means "lowered".

The marker sensors tell the panel which marker is down. The profile declares **“No”**, **“One”** or **“Both”** ([The profile](profile.md)). Open the context menu of a marker sensor as in [Sensor settings](sensor-settings.md).

| Parameter | What it does | Level |
| --- | --- | --- |
| **“Connected marker”** | **“Left”** or **“Right”**. | Agronomist |
| **“Signal "down"”** | Which state of the input means the marker is lowered. | Agronomist |

The status screen of a marker sensor shows only the common lines.

> **NOTE**
>
> **The marker sensors are wired to the tramline actuator controller.** One such controller carries the actuator **and** both marker sensors — see [Configure a tramline actuator controller](configure-tramline-actuator.md).
