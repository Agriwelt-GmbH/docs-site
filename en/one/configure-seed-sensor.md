# Configure a seed sensor

Give a new or replaced seed sensor the number of its row.

For a seed sensor the new address is simply **the number of the row** — the same number the operator sees under the column on the home screen. Prepare first as in [Device configuration](device-configuration.md): only this sensor on the cable, **“Agronomist”** level.

The address of a seed sensor can only be changed while the sensor is **working normally**. A tube sensor is ready as soon as it is connected. An **open** sensor must sit on its bracket, or be held so that **no daylight falls into the optical channel** — the gap between the two glasses. In direct light the sensor reports a permanent seed flow and does not accept the new address.

::: steps
1. Choose **“Service”** → **“Sensors Configuration”** → **“Seed sensor”** and press **“MENU”**. The menu has three items.

   ![The “Seed sensor” configuration menu.](figures/konf-seed)

2. Leave **“Sensor address”** at **“AUTO”**.

3. Select **“New address”** and set the row number with **“PLUS”** / **“MINUS”**.

4. Select **“Set”** and press **“MENU”**. The panel answers **“Done”**.

   ![The panel confirms with “Done”.](figures/info-done)

5. Disconnect the sensor and connect it again. On the home screen, check that it appears under its row.
:::

When all sensors are done, set the level back to **“Operator”**, or switch the panel off and on.
